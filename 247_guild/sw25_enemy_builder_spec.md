# SW2.5 エネミー即席作成ツール 現状仕様

更新日: 2026-08-07

## 1. 目的

公式ルールブックなどに掲載された魔物を、ゆとシートへ新規登録しなくても短時間で転記し、ココフォリア用の盤面データとして利用できるようにする。

また、サプリメントの「夢幻の魔物」自動生成ルールを使った簡易生成にも対応する。

## 2. 画面構成

- 入力画面は1カラム構成。
- 特殊能力の編集中だけ、右側に文章プレビューを追従表示する。
- 特殊能力プレビューの高さは特殊能力編集欄に合わせる。
- 入力欄はゆとシートの魔物データに近い順番と密度で配置する。
- 数値欄は2桁程度の入力を前提に幅を抑える。
- 数値文字には等幅の数字用フォントを使用する。
- 移動速度は「20（四足）／―」「20／40（飛行）」などを入力できるため、通常の数値欄より広い文字入力欄とする。

## 3. 基本データ

入力項目:

- レベル
- 名称
- 分類
- 知能
- 知覚
- 反応
- 言語
- 生息地
- 知名度／弱点値
- 弱点
- 先制値
- 移動速度
- 生命抵抗力
- 精神抵抗力

### 達成値の括弧表記

- 命中力、回避力、生命抵抗力、精神抵抗力は「基準値（固定値）」で管理する。
- 基準値を入力した場合、固定値には基準値+7を自動入力する。
- 固定値を入力した場合、基準値には固定値-7を自動入力する。
- 両方とも手動修正できる。

## 4. 部位・戦闘値

部位1つにつき以下を入力する。

- 攻撃方法（部位）
- 命中力（基準値／固定値）
- 打撃点
- 回避力（基準値／固定値）
- 防護点
- HP
- MP

### 部位管理

- 部位は追加・削除できる。
- 部位数、内訳、コア部位を管理する。
- 通常は入力された部位行から部位数と内訳を自動作成する。
- 「部位数と内訳を手動入力する」を有効にすると、掲載データどおりの表記を直接入力できる。
- 攻撃方法の末尾にある括弧内を部位名として扱う。例: `牙（頭部）` → `頭部`。
- 同名部位は通常まとめて扱う。例: 翼が2行あれば、特殊能力の適用先は `翼` になる。
- 「同名部位を個別に分ける」を有効にすると、`1部位目（翼）`、`2部位目（翼）` のように個別指定できる。

### 特殊能力の部位見出し

- 1部位だけの場合、部位見出しと適用部位選択は表示しない。
- 2部位以上の場合、`全身` と各部位名から適用先を選択できる。
- 出力時は適用先ごとに `●全身`、`●頭部`、`●翼` などの見出しを作る。

## 5. 特殊能力

### 基本操作

- 「能力欄を追加」で、能力名と説明本文を1組として追加する。
- 各能力は上下ボタンで並べ替え、削除ボタンで削除できる。
- `候補` と `名前` のどちらのタブを押しても入力方式を切り替えられる。
- 候補方式では、プルダウンから汎用能力を選ぶと名前・分類記号・本文を自動入力する。
- 名前方式では、能力名・分類記号・本文を直接編集できる。
- 候補から入力した後も、名前と本文は手動修正できる。
- 固有魔物だけが持つ能力は原則として候補化せず、直接入力する。

### 分類記号

内部出力では以下を使用する。

| 種別 | 出力 | 画面上のアイコン |
|---|---|---|
| 部位見出し | `●` | 部位見出し用記号 |
| 常時型 | `[常]` | Material Symbols `passive` |
| 戦闘準備型 | `[準]` | Material Symbols `setup` |
| 主動作型 | `[主]` | Material Symbols `major` |
| 補助動作型 | `[補]` | Material Symbols `minor` |
| 宣言型 | `[宣]` | Material Symbols `active` |

- 1つの能力に複数の記号を付与できる。
- 戦闘特技や練技の記号は、選択した要素の種別から自動集約する。
- 例: 常時特技と宣言特技を含む戦闘特技欄は `[常][宣]戦闘特技`。
- 例: 練技は通常 `[補][準]練技`。

### 現在候補に表示する汎用能力

公式エネミーデータで複数回使われる可能性が高いものを中心にする。

- 常時・基礎: 飛行、飛翔、飛翔Ⅱ、ターゲッティング、ターゲッティング＆鷹の目、弓、毒無効、精神効果無効、姿勢制御、不死の身体、人造の身体、機械の身体、通常武器無効など
- 行動回数・攻撃回数: 2回攻撃、2回攻撃＆双撃、連続攻撃Ⅰ／Ⅱ、2回行動、複数宣言
- 防御: かばうⅠ／Ⅱ、ガーディアンⅠ／Ⅱ、属性・状態への耐性、攻撃障害、根を張る、ブレス制御
- 主動作: 魔法行使、ブレス、遠隔攻撃、範囲攻撃、吸収攻撃、拘束攻撃
- 宣言: 全力攻撃Ⅰ／Ⅱ／Ⅲ、薙ぎ払いⅠ／Ⅱ、魔力撃、牽制攻撃Ⅰ／Ⅱ／Ⅲ、囮攻撃Ⅰ／Ⅱ、突進、テイルスイングⅠ／Ⅱ
- その他: 痛恨撃、再生、カウンター
- まとめ欄: 戦闘特技、練技

### 値を入力して本文へ反映する能力

- 飛行・飛翔: 命中／回避修正、失われる部位
- 2回行動: 主動作回数
- 複数宣言: 宣言回数
- 弓: 射程
- 魔法行使: 複数の魔法系統、レベル、魔力、固定値
- ブレス: 基準値、射程、対象、威力、ブレス名、属性
- 遠隔攻撃・範囲攻撃: 基準値、射程または範囲、対象数、威力、属性
- 属性・状態への耐性: 対象属性、無効／半減／軽減、軽減点
- 魔力撃: 魔力。回避力は変更せず、生命・精神抵抗力-2は固定
- 痛恨撃: 発生する出目、追加打撃点
- 再生: 回復量、タイミング、HP0以下での扱い
- 攻撃障害: 近接・遠隔それぞれの修正、守られる部位、障害部位

### 段階選択

- 全力攻撃は魔物レベル8以下でⅠ、9～12でⅡ、13以上でⅢを初期選択する。
- 全力攻撃のランクは手動変更できる。
- 効果は、Ⅰが打撃点+4、Ⅱが+12、Ⅲが+12（2H武器なら+20）。すべて回避力-2。
- 連続攻撃、薙ぎ払い、牽制攻撃、囮攻撃、テイルスイング、かばう、ガーディアンはランクを手動選択できる。
- 2回攻撃は `2回攻撃` と `2回攻撃＆双撃` を切り替えられる。

### 魔法行使

- 真語、操霊、深智、神聖、妖精、魔動機術、森羅、召異、秘奥から複数系統を追加できる。
- 表示形式は `真語魔法、神聖魔法11レベル／魔力15（22）` のように、系統をまとめる。
- レベルと魔力を調整できる。
- 固定値は魔力+7で自動表示する。

### 戦闘特技・練技

- ボックス内のプルダウンから複数選択する。
- 選択した内容を一覧表示し、個別に削除できる。
- 戦闘特技は `《...》を習得しています。` の文章を生成する。
- 練技は `【...】の練技を使用します。` の文章を生成する。
- 鷹の目は単独候補も持つが、一般的な表示用として `ターゲッティング＆鷹の目` 候補も用意する。

### ブレス

- 属性とブレス名を別々に入力できる。
- 属性を選ぶと、代表的な名称をブレス名へ反映する。
- ブレス名を選ぶと、対応する属性を推定して反映する。
- 現在の主な対応:
  - 炎 → 火炎のブレス
  - 水・氷 → 氷雪のブレス
  - 毒 → 毒煙のブレス
  - 純エネルギー → 燐光のブレス
  - ほかに土、風、雷、病気、精神効果、呪い、衝撃、断空の候補を持つ
- 名前・属性・本文は自動反映後も手動修正できる。

## 6. 特殊能力の文章プレビュー

- 実際に読む形に近い、白背景の魔物データ風プレビューを表示する。
- 分類記号、能力名、本文を出力順に表示する。
- 複数部位の場合は部位見出しごとにまとめる。
- 能力の追加、削除、並べ替え、値変更に即時追従する。

## 7. 戦利品・解説

### 戦利品

- 1行を `出目` と `内容` の2欄で管理する。
- 行を追加・削除できる。
- 初期行は `2～6：なし` と `7～：素材（100G）`。

### 解説

- 外見、行動原理、遭遇場所などを自由入力する。

## 8. 「夢幻の魔物」生成

- 画面上部に折りたたんだ状態で配置する。
- 入力はAL、PC人数、分類、性格、編成ダイス。
- ALはPCの平均レベルを表す。
- PC人数と1dの結果から、ボスの部位数・レベル修正・ザコ数・ザコレベル修正を決定する。
- ボスの魔物レベルはALに表の修正を加えて決める。
- 分類から知能、知覚、反応、言語、生息地、弱点、分類固有修正、必須能力を決める。
- 性格は、本能に従う／攻撃的／残忍／慎重／狡猾／理性的。
- 性格と魔物レベルに応じて、魔法、戦闘特技、練技を段階的に自動取得する。
- 取得段階は原則1、3、5、7、9、11、13レベル。
- 基本戦闘データは夢幻ルールのボス（コア部位）／その他部位の表を使用する。
- 生成後の全項目は手動修正できる。
- 現在はボスデータを入力欄へ生成し、ザコは生成結果の概要にレベルと数を表示する。ザコの個別データは別コマとして自動生成しない。

## 9. 出力

### ゆとシート用JSON

- ゆとシートの「別のデータを開く」のJSON入力へ渡す形式。
- 基本データ、部位データ、特殊能力、戦利品、解説を格納する。

### ココフォリア用コマJSON

- ココフォリア盤面へ貼り付けられるキャラクターJSON。
- 部位ごとにHP／MPステータスを作る。
- 生命抵抗、精神抵抗、各部位の命中、打撃点、回避のチャットパレットを作る。
- 特殊能力と解説はメモへ格納する。

### 確認用テキスト

- 卓内共有や確認用の、読みやすいプレーンテキスト。

- 各形式はコピーとファイル保存に対応する。

## 10. 現在の方針・対象外

- 候補へ採用するのは、複数の公式エネミーで使用される汎用能力を基本とする。
- 単独の魔物だけが持つ固有能力は、原則として自由入力で作成する。
- ゴーレム強化アイテムの名称・価格・グレード別効果は、エネミー能力候補には含めない。
- ゴーレム資料にある能力でも、複数の魔物へ転用できる `連続攻撃Ⅱ`、`テイルスイングⅡ`、`かばうⅡ`、`ガーディアンⅡ`、`ブレス制御` などは候補化する。
- `enemy-builder-generic-effect` の汎用効果入力UIは使用しない。
- 形態変化は現時点では汎用候補へ入れない。

## 11. 今後確認したい点

- 追加候補は、複数の公式エネミーで実際に採用されているかを資料横断で確認してから増やす。
- 英語版PDFは効果の照合に使えるが、日本語名称・記号・表記は日本語版資料を優先する。
- ゆとシートJSONの全項目について、実際の読み込み結果を継続して照合する。
- ココフォリアで複数部位コマをどう管理するかは、1コマ内の複数HPを基本としつつ、必要なら部位別コマ出力も検討する。
